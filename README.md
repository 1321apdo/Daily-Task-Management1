# تطبيق إدارة المهام اليومية والأعمال (Daily Business & Task Manager) 🚀

تطبيق أندرويد متكامل وعصري لإدارة المهام اليومية، جدولة المواعيد، تتبع المعاملات المالية والتدفق النقدي، ومدمج بمنظومة إعلانات **Google AdMob** الرسمية لتحقيق عوائد مالية مستدامة من الزوار والمستخدمين.

---

## 🌟 الميزات الرئيسية للتطبيق
- **متجر GitHub البرمجي (GitHub Developer Store):** متجر متكامل لربط حساب GitHub واستعراض مشاريعك وأكوادك وبيع تراخيص البرمجيات الرقمية مباشرة مع سلة مشتريات وتوليد مفاتيح التراخيص.
- **إدارة المهام اليومية (Task Management):** تنظيم المهام بحسب الأولويات، المشاريع، والعملاء مع فلاتر ذكية وإحصائيات إنجاز.
- **جدولة المواعيد والصفقات (Appointments & Deals):** متابعة مواعيد واجتماعات العملاء وقيمة الصفقات المالية المتوقعة.
- **محفظة التدفق المالي (Cashflow & Finance):** تسجيل الإيرادات والمصروفات وحساب صافي الربح التلقائي بالريال السعودي والدولار.
- **الخصوصية والأمان التام (PIN Lock & Privacy):** قفل التطبيق برمز حماية PIN مع وضع التمويه السري لحماية الأرقام في الأماكن العامة.
- **نظام المكافآت التفاعلي (Gamified VIP Rewards):** يحصل المستخدم على نقاط عند إنجاز المهام، مع إمكانية مشاهدة إعلانات الفيديو بمكافأة لفتح مزايا VIP.
- **يعمل دون الحاجة لإنترنت (Offline-First):** حفظ محلي مشفر وسريع باستخدام Jetpack Room Database مع دعم المزامنة السحابية.

- **معرف التطبيق (App ID):** `ca-app-pub-8214981197698574~7842643561`
- **معرف الوحدة الإعلانية (Ad Unit):** `ca-app-pub-8214981197698574/5962449630`
- **معرف إعلان المكافأة (Rewarded Ad):** `ca-app-pub-8214981197698574/5962449630`

## 🌐 ملف التحقق `app-ads.txt`
لحماية أرباحك وتوثيق ملكيتك للتطبيق لدى Google AdMob، يحتوي المشروع على ملف `app-ads.txt` جاهز:
```
google.com, pub-8214981197698574, DIRECT, f08c47fec0942fa0
```
عند رفع المشروع على GitHub، يمكنك تفعيل **GitHub Pages** ليتم استضافة الملف مجاناً على الرابط الخاص بك.

## 🛠️ البناء والتثبيت (Building the App)
المشروع مبني باستخدام:
- **لغة البرمجة:** Kotlin 2.0+
- **واجهة المستخدم:** Jetpack Compose & Material Design 3
- **قاعدة البيانات:** Room Database
- **الإعلانات:** Google Mobile Ads SDK (AdMob)

لبناء ملف APK:
```bash
gradle assembleRelease
```
أو عبر زر التصدير (Export / Download APK) في قائمة منصة AI Studio.
